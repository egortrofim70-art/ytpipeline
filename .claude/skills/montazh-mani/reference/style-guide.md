# Разбор образца: стиль «Мани»

Образец — вертикальный ролик-обзор open-source инструмента Reverse API Engineer («превращает любой сайт в API»):
33,6 с, 720×1280, 30 к/с. Автор говорит в камеру, а сверху всё время показан **сам продукт**: сайт, GitHub,
README, запись экрана. Под картинкой идут пословные субтитры. Файл образца в комплект не входит
(русская озвучка поверх английской графики).

Цифры ниже описывают образец и не являются нормами. Главное — как фраза превращается в картинку.

## 1. Как устроен ролик
| Время | Блок | Что на экране |
|---|---|---|
| 0:00–0:03,1 | Хук: «этот бесплатный AI-тул превращает любой сайт в его собственный API» | **split**: заголовок «Use Any Website's / [Hidden API]» (чёрный гротеск + белый курсив на синей плашке), под ним окно с главной сайта. На «any website» синяя рамка вокруг стикера «Turn websites», на «its own API» — вокруг «into APIs». Окно и заголовок проявляются из размытия |
| 3,1–4,0 | Усиление: «даже если у него его нет» | **face**: лицо крупно на весь кадр, белый курсив «even if it doesn't» + «have one» жирным с розовым свечением |
| 4,0–7,3 | Боль: «не надо платить за скрейпинг и дорогие API» | **split**: в окне «Skip the scraping.», на слове «scraping» выделение растёт под словом сайта |
| 7,3–9,7 | Примеры: «даже закрытые сайты: LinkedIn, Instagram, Reddit» | **white**: окно сжимается и отъезжает наверх, лицо уходит, на каждом названии над окном выпрыгивает иконка сервиса |
| 9,7–14,7 | Название: «это называется Reverse API Engineer, open-source, работает в Claude Code» | **dark**: вжух на GitHub репозитория, имя выделяется на словах; вжух на «Open source. Runs on your machine.» (выделение «Open source»); вжух на «Works with the agent you…» и список агентов, выделение «Claude Code» на словах |
| 14,7–20,7 | Как работает: «дай сайт и скажи, что нужно → агент откроет сайт → прочитает, что происходит за кадром» | **split**: README «How it works», выделение идёт по шагам **синхронно с речью**; на «агент откроет сайт» вжух на запись экрана, где браузер сам ходит по сайту |
| 20,7–24,7 | Результат: «и соберёт чистый API-клиент, которым можно пользоваться когда угодно» | **dark**: README крупнее, выделение «writes a working API client»; запись экрана «Agent mode»; вжух на шапку репо с бейджами, выделение «clean, typed client» |
| 24,7–30,1 | Преимущество: «использует тот же API, что и сам сайт, и не ломается при редизайне» | **split**: выделение «the endpoints the site actually uses»; затем мятный стикер: зачёркнуто «scraping / brittle selectors / guessing endpoints», итог «just a [typed client.]», на «весь дизайн» вокруг итога появляется синяя рамка, к нему едет курсор |
| 30,1–33,6 | Призыв: «напиши в комментах API — пришлю ссылку» | **face**: крупно, «comment» белым курсивом + «"Api"» жирным с синим свечением, автор показывает пальцем вниз |

## 2. Нарезка и ритм
- Речь сплошная: пауз длиннее 0,4 с нет, ~3,4 слова в секунду. Музыки и звуковых эффектов в образце не слышно,
  есть только голос (−14 LUFS). Возможно, это из-за переозвучки: музыка могла потеряться.
- Картинка что-то меняет каждые 1–3 с: сменилась сцена, появилось выделение, сменился скрин, выпрыгнула иконка.
  Сцен 9 за 33 с.
- Лицо есть почти всё время: в карточке внизу (split) или крупно (face). Совсем без лица идут только «экранные»
  куски (dark, white), где важно разглядеть продукт.
- Крупный план (face) появляется дважды: короткое усиление после хука и финальный призыв. Это «вдох» между экранами.
- Переходы: лицо ↔ экран — жёсткая склейка. Скрин → скрин — **вжух** (сдвиг вбок с размытием движения, ~0,25 с).
  split → white — окно плавно сжимается, лицо растворяется. Элементы появляются из размытия.
- Склейки дублей спрятаны под смену сцены или скрина.

## 3. Дизайн-система
- **Формат:** 9:16. Окно браузера сверху (≈0,13–0,49 высоты), субтитры под ним (≈0,54), лицо в карточке со
  скруглёнными углами снизу (≈0,58–1,0).
- **Фоны:** светлая «бумага» `#ECEFF4` с зерном и мягкой тенью листьев сверху (split); тёмно-серый с виньеткой
  `#545454 → #161616` (dark, лица нет); почти белый (white).
- **Окно:** светлая полоса Safari (точки, адрес с замком по центру), тонкая синяя рамка `#60A0FA` со свечением,
  скругление ~20 px, лёгкая тень.
- **Субтитры** (у нас акценты другие, см. «Что не повторяем»)**:** по 1–3 слова, каждое слово проявляется из размытия, когда его произносят. Жирный гротеск
  (SF Pro Display Bold, ~88 px на 1080), почти чёрный на светлом и белый на тёмном. **Ключевые слова** — курсивная
  антиква (Playfair Display Italic) синим `#2876F6`, на тёмном светлее и со свечением.
- **На крупном плане:** белый курсив с тенью. Ключевое слово — отдельной строкой жирным гротеском с цветным
  свечением (синим или розовым).
- **Заголовок-хук:** чёрный гротеск, вторая строка — белый курсив на синей плашке `#186CF5`.
- **Выделения на скринах:** синее выделение текста `#78ACFF` (растёт слева направо, как мышью), синяя рамка вокруг
  элемента, розовое зачёркивание, курсор macOS.
- **Стикер:** мятный `#C4ECCC`, полоска скотча, лёгкий наклон, прямая антиква, итог — розовым курсивом.

## 4. Смысл → приём
| Смысл фразы | Что показано в образце | Сцена / элемент |
|---|---|---|
| Хук: что это и что даёт | Заголовок с плашкой + главная продукта | `split` + `head` |
| Короткое усиление, эмоция, «даже…», «и это бесплатно» | Лицо крупно, фраза курсивом, ключевое слово со свечением | `face` + `subs.accent` |
| Боль, старый способ | Скрин, на слове боли выделение | `split` + `marks: select` |
| Перечисление сервисов, площадок | Белый фон, иконки выпрыгивают по словам | `white` + `icons` |
| Название продукта, «это называется…» | Тёмный фон, страница продукта, выделение названия | `dark` + `select` |
| Как работает, по шагам | README, выделение идёт по пунктам вместе с речью | `split`/`dark` + несколько `select` |
| «Он сам делает X» | Запись экрана в окне | `media` с `.mp4` |
| Сравнение «было → стало» | Стикер: старое зачёркнуто, новое в рамке | `sticky` |
| Призыв | Лицо крупно, «напиши «слово»» со свечением | `face` + accent |

## 5. Что не повторяем
- **Свечение и курсив на акцентах субтитров** (синий курсив Playfair, синее/розовое свечение на крупном плане).
  Пользователю не нравится. У нас акцент — то же слово тем же жирным гротеском и цветом, только крупнее.
- Голова «вылезает» из карточки: человек вырезан из фона, карточка — за ним. У нас это делает модель MODNet
  (`models/modnet.onnx`). В образце карточка начинается на ~0,73 высоты, глаза на ~0,78, макушка на ~0,58.
- Графика образца английская. У нас тексты русские, шрифты подобраны с кириллицей.
