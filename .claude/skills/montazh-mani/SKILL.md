# Монтаж в стиле «Мани»

Стиль снят с образца: вертикальный обзор open-source тула Reverse API Engineer, 33 с
(в комплект не входит). Разбор образца с таймкодами, дизайн-система и каталог «смысл → приём» лежат
в `reference/style-guide.md`. **Прочитай его перед первым монтажом в сессии.**

Суть стиля: зритель всё время **видит то, о чём говорят** (сайт, репозиторий, приложение), а нужное место на
экране подсвечивается в тот момент, когда звучит слово. Лицо почти всегда в кадре (в карточке снизу) и уходит
только тогда, когда экран надо разглядеть.

Скрипты (`<skill>` = `.claude/skills/montazh-mani`):
- `scripts/render.py` — рендер по `plan.json`: сцены, окно, субтитры, элементы, звук;
- `scripts/core.py` — общее ядро со «Слайдами»: нарезка дублей, вырезание повторов, элементы, сведение звука;
- `scripts/transcribe.py` — дословная расшифровка по словам;
- `scripts/check_speech.py` — поиск повторов в смонтированной речи;
- `scripts/audio_check.py` — замеры звука;
- `scripts/grid.py` — сетка координат поверх скрина, по ней снимаются рамки выделений;
- `models/modnet.onnx` — модель вырезания человека для эффекта «голова над карточкой».

Нужны ffmpeg, Python, faster-whisper, Pillow, numpy, opencv-python-headless. Всё уже установлено.
Шрифты: SF Pro Display и Playfair Display Italic, оба с кириллицей.
Материалы пользователя: `<папка с вашими материалами>` (иконки
приложений лежат в `Приложения/`).

Запуск Python: `python -E -P <скрипт>` (без `-I`, иначе не найдётся faster-whisper из пользовательских пакетов).

## Три главных правила (правки пользователя, действуют всегда)

1. **Монтаж следует за смыслом слов.** Никаких квот вида «сцена каждые 3 с». На каждую фразу спрашивай себя: *что
   из продукта здесь стоит показать и какое место подсветить?* Если показать нечего, остаётся лицо и субтитры.
   Таблица «смысл → приём» ниже и в style-guide (раздел 4).
2. **Звук подбирается под конкретный ролик, без стандарта громкости.** Речь чётко слышна, не задрана и не придушена.
   Если есть музыка, она идёт фоном и тише речи (в образце музыки нет). Порядок: замер → решение → замер итога.
3. **Слова не повторяются.** Запинки, обрывки и повторы фразы вырезаются, остаётся последнее чистое произношение.
   Ролик не отдаётся, пока `check_speech.py` не покажет «Повторов и обрывков не найдено».

## Что нужно от пользователя
- Сырое видео говорящей головы, лучше вертикальное (горизонтальное тоже подойдёт: лицо кадрируется).
- **Скрины и записи экрана того, о чём он говорит**: сайт, GitHub, README, приложение. Лучше целиком страницей
  (длинный скрин можно прокручивать `y`). Без них стиль не получится. Если их нет — спроси. Если пользователь
  разрешит, можно открыть сайт во встроенном браузере и снять скрины самому.
- Логотипы сервисов, которые упоминаются (PNG). Часть есть в `Приложения/`.

## Порядок работы

1. **Папка проекта:** `<папка проекта>/<имя ролика>/` — words.json, plan.json, `_work_mani/`, скрины в
   `screens/` (в плане `"assets"` указывает на папку со скринами).

2. **Расшифровка (дословная):**
   ```
   python -E -P <skill>/scripts/transcribe.py "<видео>" "<папка>/words.json"
   ```
   Выведи слова с таймкодами строками по фразам, чтобы видеть дубли и смысловые блоки.
   **Проверь распознавание**: whisper путает термины и английские слова («клодку» вместо «Claude Code», «обзывать»
   вместо «обходить»). Всё, что попадёт в субтитры, исправь через `subs.fix` / `subs.replace`.

3. **Замер исходного звука:** `python -E -P <skill>/scripts/audio_check.py "<видео>"`, затем реши `voice_gain_db` и
   `voice_fx`.

4. **Дубли:** `cuts.takes` — последний чистый дубль каждой мысли (секунды исходника). Паузы внутри дубля вырезает
   `max_gap` (в образце пауз больше 0,4 с нет, ставь 0,25–0,3). Повторы рендер вырезает сам. Подробности те же, что в
   скилле «Слайды»: `montazh-slaidy/SKILL.md`, шаг 4.

5. **Проверка речи до графики:**
   ```
   python -E -P <skill>/scripts/render.py plan.json --cut-only
   python -E -P <skill>/scripts/check_speech.py _work_mani/cut.mkv --edl _work_mani/edl.json
   ```
   Повторяй, пока не будет «Повторов и обрывков не найдено». Время итога смотри в `_work_mani/edl.json`
   (`out_starts`, `expected`).

6. **Сценарий по смыслу.** Разбей речь на блоки и каждому назначь сцену (`scenes`). Внутри сцены задай, что
   показано в окне (`media`) и что подсвечивается на словах (`marks`). Типичная структура образца:
   хук (split + head) → короткое усиление (face) → боль (split) → примеры (white + icons) → название и суть
   (dark) → как работает по шагам (split/dark, выделение идёт по пунктам) → «было → стало» (sticky) → призыв (face).
   Это пример, а не шаблон: структура выводится из текста конкретного ролика.

   | Что звучит | Приём |
   |---|---|
   | Хук: что это и что даёт | `split` + `head` («Используй любой сайт\n[как API]») + главная продукта в окне |
   | Короткое усиление, эмоция, «и это бесплатно» | `face` (лицо крупно) + слово в `subs.accent` |
   | Боль, старый способ, проблема | скрин + `select`/`outline` на слове боли |
   | Перечисление сервисов, площадок | `white` + элемент `icons` (иконка на каждое название) |
   | Название продукта, «это называется…» | `dark` + страница продукта, `select` на названии |
   | Как работает по шагам | README/документация, по `select` на каждый шаг, когда он звучит; длинный скрин прокручивай `y` |
   | «Он сам делает…», демонстрация | запись экрана `.mp4` в `media` |
   | Сравнение «было → стало» | элемент `sticky` (зачёркивание по словам + рамка вокруг итога) |
   | Призыв («напиши …», «ссылка в профиле») | `face` + ключевое слово в `subs.accent` (крупнее) |
   | Личное, шутка, обращение | лицо (`split` без media или `face`), только субтитры |

   Смена скрина внутри сцены — вжух (`trans: "whip"`, по умолчанию). Ставь его на слово, с которого начинается
   новая мысль. Склейки дублей прячь под смену сцены или скрина: рендер сам притягивает начало сцены к склейке
   ближе 0,3 с и печатает «Склейки на лице: …». Видимых джамп-катов должно быть мало.

7. **Рамки выделений** — доли картинки `[x0, y0, x1, y1]`. Сними их по сетке:
   ```
   python -E -P <skill>/scripts/grid.py "screens/readme.png"
   ```
   Посмотри `readme_grid.png` и выпиши рамки нужных строк, кнопок и слов. Выделение (`select`) ставь на текст,
   который **говорится сейчас**; рамку (`outline`) — на кнопку, стикер или блок.

8. **Проверка кадрами:**
   ```
   python -E -P <skill>/scripts/render.py plan.json --still 0.5,2.1,4.0,...
   ```
   Время — секунды итога. Открой сетку `_work_mani/stills.jpg` и проверь: выделение попало на нужную строку; окно не
   пустое снизу (рендер сам ужимает окно под скрин, но длинному скрину нужен `y`); субтитры не наезжают на окно
   и на волосы; голова над карточкой стоит как в образце: глаза чуть ниже края (`face_card_dy`); текст на скринах читается
   (мелкий — дай `zoom` + `focus` или сцену `dark` с большим окном).

9. **Рендер** (в фоне, ~4–5 с на секунду ролика вместе с вырезанием головы):
   ```
   python -E -P <skill>/scripts/render.py plan.json             # 1080×1920, 30 к/с
   python -E -P <skill>/scripts/render.py plan.json --preview   # черновик 540×960
   ```
   Итог кладётся рядом с исходником: `"<имя> — мани vN.mp4"`. Старые версии не перезаписывай.

10. **Итоговые проверки:** `check_speech.py "<итог>.mp4"`, `audio_check.py "<итог>.mp4"`, лист кадров итога
    (`ffmpeg -i итог -vf fps=4,scale=216:-1,tile=10x4`) — посмотри его целиком.
    Если меняешь только уровни звука: `render.py plan.json --audio-only --out "...vN+1.mp4"`.

11. **Отчёт пользователю:** какие дубли взяты и что вырезано; какие сцены на каких фразах и **почему** (смысл → приём);
    что исправлено в субтитрах; уровни звука и почему; путь к файлу. Новые устойчивые правила пользователя допиши
    в «Правки пользователя».

## Формат plan.json

Проверенный пример: `templates/plan.example.json`. Коротко:

```jsonc
{
  "source": "../../Ролик.mp4", "words": "words.json", "out": "../../Ролик — мани v1.mp4",
  "work_dir": "_work_mani", "assets": "screens",
  "face": "auto",                      // центр лица ищется сам; "face_card_dy": 0 — выше/ниже голова в карточке
  "face_pop": true,                    // голова над карточкой (модель MODNet); false — обычная карточка
  "cuts": {"takes": [[8.4, 11.5], ...], "max_gap": 0.3},   // как в «Слайдах»
  "voice_gain_db": 0, "voice_fx": {},  // по замеру
  "music": null,                       // в образце музыки нет; если нужна — как в «Слайдах», тихо и с приглушением
  "whip_sfx": null,                    // имя звука из "sfx" на каждый вжух (по умолчанию тишина, как в образце)

  "subs": {
    "accent": ["бесплатный", "любой*", 10.43],   // слова (с * — по началу) или время слова в исходнике
    "fix": {"17.68": "обходить"},               // время слова в исходнике -> верный текст ("" — скрыть)
    "replace": {"клодку": "Claude Code"},       // замена слова везде
    "max_words": 3, "max_chars": 16, "gap": 0.3, "hold": 0.9,
    "face_accent": "blue",                      // устарело: свечения больше нет, акцент просто крупнее
    "off": []                                   // [[s, e]] секунды итога без субтитров
  },

  "scenes": [
    {"at": 8.35, "kind": "split", "head": "Используй любой сайт\n[как свой API]", "head_at": [8.35, 8.6, 8.9, 9.2],
     "media": [{"src": "site.png", "url": "reverseapi.dev", "y": [0.0, 0.05],
                "marks": [{"at": 10.4, "kind": "outline", "box": [0.07, 0.67, 0.47, 0.84]}]}]},
    {"at": 11.6, "kind": "face"},
    {"at": 12.5, "kind": "dark", "enter": "whip",
     "media": [{"src": "github.png", "url": "github.com/...", "marks": [...]},
               {"at": 14.2, "src": "demo.mp4", "url": "...", "start": 3.0}]}
  ],
  "elements": [
    {"type": "icons", "at": 20.1, "pos": [0.5, 0.18], "row_at": [20.1, 20.6, 21.0],
     "items": [{"src": "C:/.../Приложения/Instagram.png", "fill": 1.0}, "🏦", "in"]},
    {"type": "sticky", "at": 25.0, "pos": [0.5, 0.3], "lines": ["скрейпинг", "хрупкие селекторы"],
     "row_at": [25.2, 25.9], "text": "просто [готовый клиент]", "outline_at": 27.1}
  ]
}
```

**Сцены** (`kind`). Сцена длится до следующей. До первой сцены идёт крупный план.

| kind | Что в кадре |
|---|---|
| `split` | светлая «бумага»; окно сверху (с `head` окно ниже); субтитры под окном; лицо в карточке снизу. Без `media` — только лицо и субтитры (`sub_y` 0,5) |
| `dark` | тёмный фон с виньеткой, большое окно, лица нет — когда экран надо разглядеть |
| `white` | белый фон, маленькое окно, место сверху под `icons`; лица нет |
| `face` | лицо крупно на весь кадр (`zoom` 1,22, медленный наезд `push` 0,04); субтитры белые на 0,70 высоты |

Поля сцены: `at`/`at_out`, `enter` (`cut` | `whip` | `fade` | `morph`; по умолчанию: с лицом — `cut`, окно → окно
другой сцены — `morph`), `head` + `head_at` (время каждого слова заголовка; строка целиком в `[...]` — белый
курсив на синей плашке, `[слово]` внутри строки — синий курсив), `head_y`, `card` (своё окно `[x0, y0, x1, y1]`),
`fit: false` (не ужимать окно под скрин), `sub_y`, `bg` (`paper` | `dark` | `white` | файл), `intro` (окно
проявляется из размытия; по умолчанию у первой сцены), `face_zoom`, `face_dy`, `zoom`, `push`.

**Медиа в окне** (`media`, по порядку): `src` (PNG/JPG или видео), `at` (с какого слова показывать; у первого можно
не указывать), `url` (адрес в полосе Safari), `trans` (`whip` | `fade` | `cut`), `y` (прокрутка: доля высоты
картинки сверху, число или `[от, до]`), `zoom` (`[от, до]`), `focus` (`[x, y]` — центр наезда), `start`/`speed`
(для видео), `marks`, `cursor` (`[[время, x, y], ...]` — курсор едет по точкам; доли картинки).

**marks:** `{"at": время слова, "kind": "select" | "outline" | "strike" | "underline", "box": [x0, y0, x1, y1],
"until": ..., "color": ...}` — доли **картинки**, не кадра.

**Элементы:** `icons`, `sticky` и все типы «Слайдов» (`caption`, `tag`, `bubble`, `stats`, `image` и т. д. — см.
`montazh-slaidy/SKILL.md`). `pos` — `[x, y]` в долях кадра. Элемент живёт до конца своей сцены или до `until`.

## Если чего-то не хватает
Новый элемент добавляй классом в `render.py` (`draw(tl)` → RGBA, `dynamic = True`, если он анимируется,
`vscale = 1.0`, размеры в пикселях при ширине 1080). Зарегистрируй его в `TYPES` и допиши в этот файл.
Новый вид сцены добавляется в `KINDS`.

## Голова над карточкой
В сценах `split` человек вырезается из фона моделью `models/modnet.onnx` (MODNet, onnxruntime, ~50 мс на кадр).
Его голова выходит над верхним краем карточки, как в образце. Карточка в этом режиме ниже: `[0.04, 0.70, 0.96, 1.04]`.
Над ней отдана полоса `pop_ext` (0,17 высоты), верх полосы растушёван.
- Глаза должны быть чуть ниже края карточки, а волосы не должны залезать на субтитры. Это регулирует
  `face_card_dy` в плане или `face_dy` у сцены (по умолчанию 0; больше — голова выше, меньше — ниже). Крупное лицо
  у камеры (как в «Эпизоде 06») уже на 0 стоит хорошо.
- Выключить: `"face_pop": false` для всего ролика или `"pop": false` у сцены. Если модели нет, рендер пишет об
  этом и рисует обычную карточку.
- Проверяй кадрами край волос и руки: рука, поднятая выше края карточки, тоже вырежется и окажется поверх фона.
  Это нормально, так было и в образце.

## Правки пользователя
- Монтаж подстраивается под смысл слов ролика, а не под проценты и частоты из образца.
- Звук без фиксированного стандарта: речь чётко слышна, не завышена и не занижена; музыка не громкая; уровни
  подбираются по замеру каждого ролика.
- Слова не повторяются: запинки, обрывки и повторы фразы вырезаются. Перед сдачей — `check_speech.py` по итогу.
- Акцент в субтитрах — то же слово тем же шрифтом и цветом, только крупнее (~1,3×). Никакого синего/розового
  свечения, обводки и курсива на акцентах — ни на крупном плане, ни на экранах.
- Цветокоррекция обязательна: человек в кадре не должен быть тусклым и серым. Рендер сам переводит HDR iPhone
  (HLG/PQ) в SDR (hable) и кладёт «живой» цвет по референсу: светлее, кожа персиковая, стена голубая без зелени
  (`LOOK` в `render.py`). `"grade": false` — выключить, `"grade": "<фильтр ffmpeg>"` — свой. Проверяй лицо на кадрах.
