# Стиль «Видеоэссе»: разбор образцов

Образцы (горизонтальные 1920×1080, ~2 мин, закадровый голос, лица автора в кадре нет):
- **A** (в комплект не входит): «5 секретов Мистера Биста», 128 с, 30 к/с.
- **B** (в комплект не входит): «Сколько зарабатывают монтажёры блогеров»,
  135 с, 60 к/с.

## 1. Суть

Это видеоэссе для YouTube под голос за кадром. Экран всё время занят одним из двух:
1. **Сказанным словом.** Чёрный жирный гротеск на чистом белом фоне, слова появляются ровно тогда, когда звучат.
2. **Тем, о чём говорят.** Фрагмент того самого ролика, человека или сайта в скруглённой карточке с тенью, часто с
   подписью «как на YouTube» (название, канал, просмотры).

Текст и картинка чередуются по смыслу. Пока идёт рассуждение, связки и выводы («но всё это не сработает, если…»,
«тебе нужна одна простая формула»), на экране текст. Как только назван конкретный пример (ролик, блогер, цифра),
на экране этот пример. Обычно текст и карточка не стоят вместе: на карточке своя подпись, субтитров нет.

Темп высокий. Фраза-кусок текста держится 0,4–1,2 с, кадр внутри карточки меняется каждые 0,7–2 с. Пауз в речи
почти нет, всё сшито вплотную.

## 2. Дизайн-система

| Что | Значение |
|---|---|
| Кадр | 1920×1080, 30 к/с (B — 60) |
| Фон | белый `#FFFFFF`; тёмные сцены — чёрный `#000` |
| Шрифт | гротеск уровня Helvetica Neue / SF Pro Display Bold, **плотный трекинг** (буквы почти касаются, ≈ −0,045 em), строчные |
| Текст-фраза | ~110–130 px, по центру кадра, 1 строка, 1–4 слова |
| Главное слово | 200–260 px, может быть капсом («ЭМОЦИИ», «НО», «ЭФФЕКТЫ», «ОГРОМНЫЙ ПАК») |
| Подстрока | ~0,5 от основной, сразу под ней («Гиперреальность» / «все выкручено на max») |
| Акцент | ярко-зелёный `#2BD84A` с мягким зелёным свечением: одно слово или «термин – пояснение» («таймер - создаёт напряжение») |
| Карточка | скругление ~22 px, мягкая тень (0 20 50 rgba(0,0,0,.25)), 16:9; с подписью ~1335 px шириной (0,70 кадра) и сверху ~75 px; без подписи до 0,8 кадра, по центру |
| Подпись карточки | название ролика жирным ~58 px; ниже аватар канала + имя ~44 px; справа серым «185M views» |
| Тёмные сцены | в образце — чёрный фон и белый светящийся текст, «act 1:» над главой. **У нас текст только на белом** (раздел 6); тёмный фон — лишь под видео |
| Звук | музыкальная подложка всё время, на ~8 дБ ниже речи; whoosh на переходах, глухой удар на ключевых словах, щелчки на появлении объектов |

## 3. Анимации

- **Появление слова.** Буквы по очереди (шаг ~1 кадр) выезжают снизу-справа на ~0,3 em из размытия 8–10 px в
  резкость за ~7 кадров. Фраза раскладывается заранее по центру, слова встают на свои места по мере произнесения:
  поэтому недоговорённая фраза стоит не по центру («на все» → «на все случаи»).
- **Смена фразы.** Старая фраза исчезает резко, новая сразу начинает появляться (жёсткая смена).
- **Карточка.** Появляется резко или с коротким «вдохом» (масштаб 1,04 → 1 за 6 кадров). Внутри медленный наезд.
  Кадры внутри карточки меняются жёсткими склейками; подпись не меняется, пока это тот же ролик.
- **Переходы между сценами** (по частоте):
  1. жёсткая склейка (основной);
  2. **толчок вверх** (`push`): старая сцена уезжает вверх, новая въезжает снизу, с вертикальным размытием (B, 0:00);
  3. **круг** (`circle`): белый круг раскрывается из центра поверх чёрного, внутри уже новая сцена (B, 0:00 и 1:30);
  4. **размытие** (`blur`): новая сцена проявляется из размытия с лёгким увеличением;
  5. **вспышка** (`flash`): 1–2 кадра серого/чёрного между белыми сценами (A, 0:40 «если не понять» → тьма).
- **Набор слов** (`scatter`): слова прилетают из разных точек и собираются в фразу (B, 1:13 «цены начинаются от 10к
  рублей»).
- **Стена роликов** (`wall`): превью YouTube на выгнутой (цилиндр) стене, камера медленно едет, поверх — светящийся
  текст «200 миллионов» (A, 0:04–0:10).
- **Коллаж** (`grid`): сетка 3×3 кадров встык, в центре плашка-подпись «все видео» (A, 0:01–0:03).
- **Объекты.** Эмодзи Apple, иконки (папка «Secret Pack», логотип канала, YouTube, часы) выпрыгивают с пружиной
  на своём слове; курсор нажимает на папку.
- **Виджеты.** Белая карточка-статистика «Просмотры 1.061.903» с зелёными таблетками; цифра пересчитывается
  (74% → 82%); график удержания рисуется линией.
- **Таймер** в правом верхнем углу, серый, отсчитывает назад (A, «таймер создаёт напряжение»).
- **Нумерация.** Огромная цифра «1.», «2.», «3.» слева от карточки, когда перечисляются примеры (B, 1:00).
- **Наклонные карточки** (`tilt`): две вертикальные карточки (рилсы) в перспективе на чёрном (B, 1:16–1:22).
- **Призыв.** Карточка с QR-кодом, ник «@ваш_ник», под ней фраза «ссылка в описании» / «я выложил в ТГ».

## 4. Смысл → приём

| Что звучит | Приём |
|---|---|
| Хук-обещание («я проанализировал все видео…») | текст на белом; затем коллаж/стена из материала, о котором речь |
| Число, деньги, просмотры | главное слово крупно («200 миллионов», «12.000$») или виджет со счётчиком |
| Рассуждение, связка, вывод | `text`: слова на белом фоне |
| Конкретный ролик / блогер / пример | `card` с этим роликом и подписью «как на YouTube» |
| Перечисление «три элемента: А, Б, В» | каждый пункт — термин крупно (+подстрока-пояснение с зелёным акцентом), затем пример-карточка |
| Перечисление людей/примеров «1, 2, 3» | `card` с `num` («1.», «2.», «3.») |
| Новая глава, новый персонаж | `act`: серое «act 2:» + имя чёрным на белом |
| Эмоция, контраст («но», «эмоции») | `big`: одно слово огромным, удар в звуке |
| Подарок, пак, гайд | объект (папка, эмодзи) + курсор-клик; затем QR |
| Призыв («заходи в ТГ», «ссылка в описании») | `qr` + фраза под ним |
| Технический термин (джамп-кат, спид-рамп) | `full` или `card` с примером этого приёма, слово поверх или рядом |

## 5. Структура образцов

**A (128 с):** чёрное интро с текстом (0–1) → коллаж «все видео» (1–3) → «5 главных секретов» на тёмной карточке
(3–4) → стена роликов «200 миллионов» (4–10) → объекты YouTube/часы «за пару минут» (10–11) → «я раскрою» + эмодзи
(11–13) → короткие клипы денег (13–15) → папка Secret Pack + курсор (15–17) → «Бист использует 3 элемента» текст →
«Гиперреальность / все выкручено на max» → карточки-примеры с подписями → «визуальные триггеры» → карточки → «НО»
крупно → вспышка в тёмный кадр «как работать с кадрами» → текст → карточки → «но что затягивает…» → «так это
музыка» поверх полноэкранного кадра → карточки → стена комментариев «более 100 миллионов» → виджеты статистики
(«твои ролики») → «ОГРОМНЫЙ ПАК» + QR → «ЭМОЦИИ» → график удержания с «?» → карточки → «таймер — создаёт
напряжение» с таймером → карточки → «формула» → «ЭФФЕКТЫ» → примеры каждого эффекта (джамп-кат, кат, спид-рамп)
→ CTA: QR «ссылка в описании» → шутка «Shot on iPhone».

**B (135 с):** круг «окей» → прокрутка YouTube-ленты в окне → текст «я постарался…» → три LEGO-фигурки героев →
«act 1: Iman Gadzhi» → его ролики на тёмном → текст «при этом следуя 3 моментам» (тёмный) → карточки с примерами →
текст «но прикол в том…» → поиск каналов на YouTube (запись экрана) → карточки → «300-400к» крупно → круглое видео
из ТГ → нумерованные примеры 1-2-3 → «act 3: рилсы для медийных лиц» → «цены начинаются от 10к рублей» (scatter) →
наклонные рилсы на чёрном → «12к 15к» светящиеся цифры → карточки → круг → текст → QR «я выложил в ТГ» → «act 4:
Мистер Бист» → карточки → «12.000$» на чёрном → текст → карточки → QR «в моём ТГ».

## 6. Что брать из образца, а что нет

Брать: систему (белое/текст ↔ карточка-пример), типографику, анимации, звуковую подложку.
Не брать: квоты («переход каждые N секунд»), конкретные темы и примеры. Каждый ролик строится от смысла своих слов
(правило пользователя).

**Отличия от образца по правкам пользователя (важнее образца):**
- В образцах есть тёмные текстовые сцены (интро «я проанализировал», главы «act 1:» на чёрном со свечением).
  У нас так **нельзя**: текст на фоне — всегда белый фон и чёрный текст. Тёмное — только под видео.
- В образцах много жёстких склеек и вставок по 0,2–0,5 с. У нас монтаж **плавнее, в духе Apple**: по умолчанию
  мягкий переход (старое тает до стыка, новое проявляется после), вставки не короче ~0,8 с, фразы не мелькают и
  не стоят друг на друге, кадры в карточке меняются растворением. Жёсткая склейка — только как осознанный акцент.
