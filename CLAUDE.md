# ytpipeline — YouTube-канал, видео-эссе формата "What if"

Канал в стиле топовых "¿Y si...?"/"что если..." roликов: анимированный
стикмен-персонаж + счётчик-эскалация + факт-карточки. Основной язык канала —
**испанский** (у юзера уже есть структура папок под англ/исп/рус). Текущее
тестовое видео — про **фатальную семейную бессонницу** (insomnia familiar
fatal), делается сейчас на русском для проверки пайплайна, потом переводится.

## Персонаж (Character.tsx)

Стикмен-стиль по референсам топового испаноязычного канала "¿Y si...?" —
**НЕ толстый 2D-блоб**, а тонкие линии-конечности:

- Голова: круг, градиент (`radialGradient`) для лёгкого объёма вместо
  плоской заливки, `HEAD_R=58`
- Шея: отдельная трапеция, физически соединяющая голову и кофту (была
  критическая задача: голова "левитировала" на 33px над телом — формула
  `headCenterY` чинилась дважды, итоговая верная версия в коммите `38e4b60`)
- Тело: короткая трапеция-кофта (`shirtColor`, дефолт `#FFD400` жёлтый),
  штаны — тонкая линия `pantsColor` (`#111111`)
- Руки — тонкие линии **цвета кофты** (не головы — это баг, который правили)
- Лицо: брови есть не у всех эмоций (`browY: -100` = сентинел "без бровей",
  как у референсов в neutral/happy); рот параметризован 3 числами
  (`mouthWidth/mouthCurve/mouthOpen`) — это даёт **плавную интерполяцию
  между эмоциями** вместо жёсткой подмены на стыке сцен
- Моргание — независимо от эмоции, период 110 кадров
- Свечение (`glow`) — мягкий цветной ореол позади персонажа, чтобы чёрная
  голова не сливалась с тёмным фоном (жалоба юзера была "левитирует,
  плоско, не видно на фоне")
- Поза "лёжа в кровати" — **НЕ** через поворот рига на 90° (давало
  "флажок" вместо тела и кривое лицо), а через обычную вертикальную позу
  персонажа + div-"одеяло" поверх нижней части

## Структура ролика (подтверждена разбором 7+ роликов-референсов)

1. Хук-вопрос в начале ("¿Y si...?" / "А что если...")
2. **Счётчик, который тикает весь ролик** — главный движок вовлечения у
   всех топовых каналов (часы без сна / дни / км/ч — что угодно
   эскалирующее). В `HoursCounter` реализовано как `interpolate` от
   `startHour` до `endHour` за длительность сцены
   - "DÍA N" тоже вариант счётчика (по дням вместо часов)
3. Факт-карточки на тёмном фоне с рамкой — вставки с реальной
   фактурой/историческими фактами
4. Экспрессивное лицо (брови решают) — наш риг это поддерживает
5. Переходы между сценами — `SceneFade`: кроссфейд + лёгкий Ken Burns
   zoom, НЕ жёсткие склейки

Настройки шаблона "рус" (уже оттюнены юзером): `speed: 1.07`,
`stability: 0.75`, `similarity_boost: 0.75`, loudness norm -16 LUFS. Speed
1.07 был настроен под **другой, более быстрый** формат (слайд-шоу
сторителлинг, фото на каждые 2-4 сек речи) — для текущего формата с
анимированным персонажем, возможно, стоит протестировать на 1.0 (открытый
вопрос, юзер ещё не подтвердил финальное решение).

**Не создавай новые тестовые шаблоны** — пользуйся готовыми "рус"/"исп"/"англ".

Процесс заказа озвучки: `POST /templates/{id}` → нет, заказ создаётся через
`POST /orders` с `template_id` + `input_text`. Статус заказа часто висит в
`pending` по 3-5 минут даже на короткий текст — это нормально для Lumean,
не баг, просто жди/поллингуй в фоне. После `completed` — субтитры и аудио
скачиваются через `POST /storage/url` с путём из `result.files`/`service_files`.

### Обязательные правила стиля (валидированы разбором чужого style.md того же жанра)

Независимо пришли к тем же трём правилам, что у другого канала в точно таком
же стикмен-жанре (`what-if-stickmen/references/style.md`), после того как
юзер сам несколько раз ловил нас на нарушении этих же правил — так что
держать их явно, не полагаться на память между сессиями:

- **Камера никогда не стоит на месте** — уже реализовано через `SceneFade`
  (лёгкий Ken Burns) + `CameraCloser` (псевдо-наезд с пересчётом центра) на
  каждой сцене без исключений.
- **Главный герой — нормального размера, не "малыш" вдалеке** — камера
  должна держать персонажа крупно в кадре, а не мелкой фигуркой посреди
  сцены (юзер явно жаловался на это раньше).
- **Персонажи всегда что-то делают** — ни одной сцены с полностью статичной
  позой + сменой только выражения лица/зума; должно быть видимое действие
  (листает телефон, ворочается, тянется, садится и т.п.), меняющееся
  минимум каждые 2-5 секунд.

Также подтверждено цифрами из чужого разбора retention: зрители отваливаются
**до первой секунды самого видео** — то есть титульная заставка/надпись в
начале убивает ролик сильнее всего. У нас уже с этим согласовано: хук идёт
сразу голосом, без текстового титра-"что если" в начале (см. `InsomniaFullES`/
`PainFullES` — но `SleepDemo30s`/`HookText` всё ещё используют титр, это
старый тестовый ролик, не финальный формат).
